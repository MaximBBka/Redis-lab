Это тестовая лаба для тренировки работы с Redis

Как запустить:
1. Запускаем контейнеры
- docker-compose up -d

Как тестировать:
1. Можно зайти внутрь контейнера с Redis и поизучать синтиксис работы с базой.
2. Провести тестовое сравнение работы PostgreSQL без Redis и вместе с Redis.
- Скачайте Postman для удобного просмотра статистики.
- Проверьте что все работает сделав запросы:
- localhost:8081/product/1
- localhost:8080/product/1
3. Создайте 2 runner в Postman на 100 пользователь.
- Первый runner для запросов: localhost:8081/random_product (C REDIS)
- Второй runner для запросов: localhost:8080/random_product (БЕЗ REDIS)

В результете увидите что при использование Redis запросы выполняются в 2-3 раза быстрее.
